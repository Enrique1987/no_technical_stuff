# Catálogo de fantasía

Fuente única: [inventario Markdown](../knowledge/books/fantasy_library.md). La web lee directamente ese archivo; no mantiene un JSON duplicado. Las clasificaciones se derivan de las secciones y títulos mediante reglas en `index.html`; las nuevas entradas desconocidas quedan sin clasificar.

## Publicación

En Settings → Pages, seleccionar Deploy from a branch, `main`, `/ (root)` si no existe ya una configuración compatible. La web se encontrará en `/no_technical_stuff/fantasy/`. Si Pages ya usa otra fuente, integrar ambos archivos y el inventario en esa publicación sin reemplazarla. El repositorio es público: no añadir información privada al inventario.

## Gestión

[Catálogo en ChatGPT](https://chatgpt.com/space/page_c8147e6795788191a7702f4544213d31). Actualizar primero el Markdown; la web se actualiza al desplegar la rama. El Espacio requiere actualización manual; no hay sincronización automática. Mantener encabezados y tablas de inventario compatibles. La trilogía Orcos se muestra como una entrada agrupada, no tres ejemplares.
