# Calisthenics

The three saved clips focus on handstands and their progressions: [balance cues](videos/Dbn4laHPOsd.mp4), [press-to-handstand progressions](videos/DUX0FSKk95o.mp4) and a [handstand/headstand montage](videos/DX7FTAtyewY.mp4). The [full index](videos/) retains the creators and original URLs.

Use them as examples of positions and drills. A montage does not define a safe starting level or prove a progression will work for everyone.
